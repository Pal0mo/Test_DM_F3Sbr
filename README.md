 # Test_DM_F3Sbr

 Notre projet de stage consistait à imposer des contraintes sur un modèle de matière noire particulier. 
 On suppose dans notre cas que la matière noire est une particule, qui interagit avec le modèle standard grâce a une particule médiatrice. 

 L'objectif est le suivant : On fait des simulations sur le modèle avec Madgraph5, un logiciel, puis on réinterprète les données expérimentales obtenues au LHC ces dernières années avec celles ci sur Madanalysis pour en déduire des contraintes sur le modèle .
Une première partie du projet a été consacrée a la prise en mains des outils numériques. 


Le rapport.pdf présente le projet plus en détail, la physique associée, le contexte et les résultats obtenus a la fin du stage. 
Dans le fichier __journal_de_bord.pdf__ on trouve le déroulé semaine par semaine de nos avancées, ainsi que les détails techniques à savoir, notamment les différents modules/ packages à installer ou les erreurs qu'on a pu rencontrer.
