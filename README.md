  ## présentation du projet 
 Notre projet de stage consistait à imposer des contraintes sur un modèle de matière noire particulier. 
 On suppose dans notre cas que la matière noire est une particule, qui interagit avec le modèle standard grâce a une particule médiatrice. 
 Le rapport.pdf présente le projet plus en détail, la physique associée, le contexte et les résultats obtenus a la fin du stage. 

 Les objectifs sont : 
 
 - prise en main des outils madgraph5 et Madanalysis5
 -  prise en main du terminal linux
 - compréhension via de premières simulations de la physique et enjeux associés au projet
 - création d'un code pour réinterpréter les données expérimentales obtenues au LHC ces dernières années avec nos simulations sur Madanalysis5 pour en déduire des contraintes sur le modèle F3sBR
 - rédaction d'un rapport de stage complet et rigoureux
